# DESK-Companion

**The Android companion to DESK — an open-source desktop AI assistant.**

DESK-Companion is part of the broader DESK ecosystem, an open-source project exploring practical ways to bring AI into everyday computing.

The project focuses on extending the DESK ecosystem to Android, with an emphasis on accessibility, simplicity, and open development.

## About

DESK-Companion is the Android-focused part of the DESK ecosystem. It has its own repository while complementing the main desktop application.

The project is being developed in the spirit of open-source software: making code accessible, encouraging experimentation, and giving contributors the opportunity to participate in its evolution.

## The DESK Ecosystem

- **[DESK](https://github.com/Saksham-garg2008/DESK)** — The main desktop AI assistant.
- **[DESK-Companion](https://github.com/Saksham-garg2008/DESK-Companion)** — The Android companion project.
- **[DESK Website](https://Saksham-garg2008.github.io/DESK-Website/)** — The project's public-facing website.
